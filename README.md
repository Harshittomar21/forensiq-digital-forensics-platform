# ForensiQ

A modern, dependency-free Python prototype for digital-forensics investigation workflows.

## Features

- Investigation command center with risk, integrity, evidence and entity metrics
- Evidence register, custody trail, fingerprint stubs and artifact detail views
- Controlled acquisition workflow and timeline reconstruction
- Relationship graph and downloadable Markdown investigation brief
- Fictional demo data for classroom demonstrations

## Run locally

```bash
python3 forensics_app.py
```

Open `http://127.0.0.1:8088`.

> Educational prototype only. Do not use it for live evidence without appropriate validation, access controls, immutable storage and organisational procedures.
